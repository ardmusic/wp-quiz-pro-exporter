## 2024-08-01 - Preventing Input Label Nesting & Improving Async Form UX
**Learning:** Nesting multiple interactive elements (such as select dropdowns and submit buttons) within a single `<label>` tag creates a confusing experience for screen readers. Using proper `for` attribute mapping with `screen-reader-text` provides cleaner accessibility. Additionally, since file downloads via form submissions don't trigger a page reload, updating the button's text to "Exporting..." and disabling it via a `setTimeout(..., 0)` inside the form's `submit` handler ensures the browser initiates the form request before the element is disabled.
**Action:** Always separate the label from the actual interactive elements, linking them via the `for` attribute and `id`. Use the submit event with a zero-delay timeout to safely trigger loading feedback for background file download forms.
