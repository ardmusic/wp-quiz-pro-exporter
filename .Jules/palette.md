## 2025-10-04 - Un-nesting Form Elements for Screen Readers & File Download Loading States
**Learning:** Wrapping both `<select>` and `<input type="submit">` inside a single `<label>` tag breaks accessible screen-reader navigation and causes multi-input association confusion. In addition, file export forms (e.g. `admin-post.php`) trigger a browser file download without re-rendering the page, which requires client-side UI states to reset after a brief delay rather than waiting for a page navigation.
**Action:** Always un-nest interactive controls into standalone elements with dedicated `screen-reader-text` labels using `for` attribute matching, and use `setTimeout` within form submit handlers to provide localized loading feedback (`Exporting...`) and auto-reset button states.
