## 2024-08-02 - Nesting Interactive Elements & Admin Post CSV Actions
**Learning:** Nesting multiple interactive elements (such as a `<select>` and a submit button) inside a single `<label>` is an accessibility issue that confuses screen readers and breaks keyboard navigation. Additionally, handling loading state for non-page-reload requests (like CSV downloads triggered via admin-post.php) requires capturing the form's `submit` event instead of a button's `click` event, and using a zero-delay `setTimeout` to disable the submit button so the browser registers the submit payload first.
**Action:** Always un-nest `<select>` and `<input type="submit">` from inside `<label>` tags. Ensure each interactive control has its own clean, accessible description (such as screen-reader-text spans). When disabling buttons during form submits, always defer the disabling/disabling using a 0ms setTimeout to prevent the submit event payload from being swallowed by the browser.
