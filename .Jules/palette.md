## 2025-01-20 - Non-blocking submit buttons for file downloads
**Learning:** In WordPress or other traditional MVC apps, CSV exports triggered by POST requests typically download files instantly without reloading the page. Disabling a submit button on click can block the browser from sending the form request if done synchronously. Using a combination of form submit interception, `setTimeout(..., 0)` to defer disabling, and a 2-second timeout to restore the button's state provides immediate feedback while preventing double submissions and ensuring the download triggers smoothly.
**Action:** For background file export operations, always use `setTimeout(..., 0)` to allow form processing before disabling the button, and use a reasonable automatic timeout to re-enable the button to handle the non-navigation download behavior.
