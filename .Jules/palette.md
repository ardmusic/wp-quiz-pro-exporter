## 2025-05-14 - HTML entities in JavaScript .val()
**Learning:** Using jQuery's `.val()` to set the value of a form element (like a button) with a string containing HTML entities (e.g., `&hellip;`) renders the entity literally rather than the intended character.
**Action:** Use literal characters (e.g., `...` or `…`) in localized strings meant for JavaScript-driven UI updates to ensure correct visual representation.
