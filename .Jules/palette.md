## 2024-08-04 - Accessible Form Nesting and Micro-UX Loading Pattern
**Learning:** Nesting multiple interactive elements inside a single `<label>` is highly inaccessible to screen readers. For download operations or triggers that don't reload the page (e.g. `admin-post.php` attachment responses), disabling the button directly inside the submit listener requires wrapping it in a `setTimeout(..., 0)` to allow the browser to process the form submit and form-data payload first. It is also beneficial to use a 2-second timeout to re-enable the button as a fallback for standard file downloads.
**Action:** Always avoid nesting `<select>` and `<input>` under `<label>`. Bind separate `<label>` and `.screen-reader-text` labels with matching ID `for` attributes. Implement the `setTimeout(..., 0)` disabling pattern on submit.
