## 2025-01-20 - Accessible Select Labels and Dynamic Loading Feedback
**Learning:** In WordPress admin interfaces, nesting input controls (like `<select>` or other `<input>` elements) inside a single `<label>` can confuse screen readers and lead to unexpected label associations. It is much better to separate the label and control, referencing the control with the `for` attribute and an explicit `id`. Additionally, buttons with symbols (like unicode arrows `&#8680;`) must have a descriptive `aria-label` to provide context. For async-like post requests (such as CSV downloads using `admin-post.php`), setting a temporary loading state on form submit improves feedback and prevents double clicks.
**Action:** Unnest elements from `<label>`, use explicit `id` and `for` attributes, add descriptive `aria-label`s on symbol-based buttons, and use scoped jQuery submit event listeners with short timeouts to manage loading states for CSV/file downloads.
