## 2026-03-30 - Accessible CSV export actions and asynchronous feedback in WordPress admin
**Learning:** WordPress admin buttons using Unicode symbols (like `&#8680; CSV`) are ambiguous to screen readers unless given explicit `aria-label` attributes. Additionally, nesting submit buttons inside `<label>` elements confuses assistive technology and DOM hierarchy. For file export actions handled via `admin-post.php` where no page reload occurs, attaching a loading state on form submit with an automatic timeout reset provides clear visual feedback and prevents duplicate form submissions.
**Action:** Always separate inputs from buttons with dedicated `<label>` tags with `.screen-reader-text`, pass localized loading text using `wp_localize_script()`, and ensure async download buttons restore their active state after timeout or on input change.
